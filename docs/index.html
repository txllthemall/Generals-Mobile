What changed in v125

Critical startup fix
Fixes the v124 “Technical Difficulties” crash caused by incorrect BIG/INI precedence while loading Zero Hour data.
Vanilla ordering restored
Base-game directory enumeration is back to the v123 behavior that correctly loads the Zero Hour INI set.
Mod overlay isolated
Mod-only recursive discovery no longer changes vanilla base-game archive enumeration.
v124 features preserved
Mod loose-file overrides and mod BIG override priority remain available.
Renderer selection preserved
Vulkan/DXVK, native GLES3 and GLES3 through ANGLE remain selectable.
Performance work preserved
MYSOREZ v1.2.0 rendering, shadow LOD and Android optimizations remain included.

Run a mod

Install v125

Install the APK and configure your legally owned Zero Hour game-data folder in Setup.

Open the game icon

The pre-launch selector offers base game, mod-folder selection and the currently selected mod.

Select the mod folder

Pick the folder containing the mod files. The original game folder is not modified.

Launch selected mod

Mod files get priority over matching base assets. Use “Launch base game” whenever you want vanilla Zero Hour.

Game files are not included. The APK contains engine code only. You must provide game data from a legally owned copy of Command & Conquer: Generals — Zero Hour.
