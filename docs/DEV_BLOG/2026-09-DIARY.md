# Development Diary - September 2026

## 2026-09-06: Import upstream v1.2.0 for Generals Mobile v124

Integrated the cumulative Android and engine changes from MYSOREZ's v1.2.0
snapshot, including native GLES/ANGLE rendering, buffer/cache performance work,
rendering correctness fixes, dynamic shadow LOD, game-folder diagnostics,
online-session error handling, crash diagnostics and smaller CI APKs.

Resolved the Android-only CMake, SDL initialization, gesture-navigation and version
conflicts while preserving the gamepad/cursor, touch controls, audio fixes,
rotation and Adreno allocation workaround. Kept Vulkan as the default for
upgrades from v123 and advanced the Generals Mobile version to 124.

Verified the ordered DXVK patches and repeat application, the merged patch against
SDL 3.4.2, 15 native renderer-selection cases, shell/workflow syntax, all Android
resource XML, translated picker completeness and the ANGLE ELF metadata.
The existing pull-request workflow provides full Android build validation;
physical-device and performance checks remain pending.

See [the integration record](../port/UPSTREAM_V1_2_0.md) for source commits,
adaptations, attribution and the device validation matrix.
